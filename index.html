Сейчас сайт обращается напрямую к Gemini API с выбранной моделью и ключом выше. Поля «Адрес API» и «Доп. заголовок» нужны только если вы вместо этого хотите слать запросы на свой сервер — тогда переключите вызов обратно на них внутри функции callBackend(). Настройки хранятся только в памяти страницы (без localStorage), поэтому удобнее один раз прописать ключ и модель прямо в коде — константы DEFAULT_GEMINI_KEY и DEFAULT_GEMINI_MODEL в начале скрипта.
Ответы отправляются на ваш сервер, ключ API там и остаётся.
