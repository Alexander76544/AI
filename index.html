Ключ Gemini API теперь хранится на сервере (переменная окружения GEMINI_API_KEY в настройках проекта на Vercel) и в браузере не появляется. Страница отправляет сообщения на /api/chat — эта функция выполняется на сервере и сама обращается к Gemini.
Ответы отправляются на ваш сервер, ключ API там и остаётся.
